✨ What This Application Does

Imagine you say to a voice assistant: "Play some jazz in the kitchen." A good language-understanding system has to work out two things at once. First, the intent — the person wants music played. Second, the slots — the genre is jazz and the location is the kitchen. This application measures how reliably a model gets both parts right.

It does that by working through a large collection of realistic sentences from the Snips dataset, comparing the model's answers against the known correct answers, and turning the comparison into easy-to-read scores.

🎯 Intent Classification

Checks whether the model correctly identifies what the person is trying to do, such as asking for the weather, setting an alarm, or booking a restaurant.

🧩 Slot Filling

Checks whether the model correctly picks out the important details inside the sentence, like a time, a city name, or a song title.

⚡ Zero-Shot Testing

Measures how well the model performs on categories it has never been trained on, with no examples to learn from first.

🔁 Few-Shot Testing

Measures how much the model improves when it is given a small handful of example sentences before being tested.

📊 Understanding Your Results

The summary screen uses a few simple figures. You do not need a statistics background to interpret them.

  • Overall accuracy: The percentage of test sentences where the model got the complete answer right. A higher number is better.
  • Intent accuracy: How often the model correctly identified what the user wanted to do.
  • Slot score: How often the model correctly identified the extra details inside the sentence. This score is stricter, because every detail must be right.
  • Confusion breakdown: A list showing which categories were mixed up with which. This is the most useful section for spotting patterns.
  • Run summary file: A plain text record of the settings used and the scores produced, useful for repeat comparisons.

If a score looks surprisingly low, compare a short run against a long run first. Small samples naturally jump around more than large ones.

📚 Plain-English Glossary

  • NLU (Natural Language Understanding): The part of a computer system that works out what a person means when they speak or type.
  • Intent: The action a person wants to happen, such as "set an alarm".
  • Slot: A detail attached to that action, such as "7 a.m." for the alarm.
  • Benchmark: A standard set of test sentences with known correct answers, used to compare performance fairly.
  • Zero-shot: Being tested on categories with no examples provided beforehand.
  • Few-shot: Being tested after receiving a small number of examples.
  • Snips dataset: A widely used public collection of realistic assistant-style sentences used for testing language understanding.
  • Token classification: Labeling individual words inside a sentence, which is how slots are found.
